## 🎨 Дизайн и UX

## 🔧 Технические детали

### Стек технологий
- ✅ **Next.js 15** (App Router)
- ✅ **TypeScript (strict mode)**
- ✅ **TanStack Query v5** для data fetching
- ✅ **React Hook Form** в поисковой форме
- ✅ **TailwindCSS** для стилей
- ✅ **Lucide React** для иконок

### Архитектура (FSD)
```
app/(public)/events/past/page.tsx          # 🟢 Layer 6: App
├── widgets/events/layout/past-events-page  # 🔵 Layer 4: Widgets
│   ├── widgets/events/hero/past-events-hero
│   └── widgets/events/catalog/events-catalog
├── features/event/search                   # 🟡 Layer 3: Features
├── entities/event                          # 🟣 Layer 2: Entities
└── shared/api/eventService                # ⚪ Layer 1: Shared
```

### Производительность

| Метрика | Значение | Комментарий |
|---------|----------|-------------|
| Stale Time | 5 минут | Прошедшие события редко обновляются |
| Limit | 50 событий | Достаточно для каталога без пагинации |
| Retry | 3 попытки | Автоматические повторы при ошибках |
| Cache | TanStack Query | Клиентское кеширование |
