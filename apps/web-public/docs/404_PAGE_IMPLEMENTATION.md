# Документация: Реализация страницы 404

## Обзор

Реализована custom страница 404 (Not Found) для проекта Eventflow, полностью соответствующая дизайн-системе проекта и лучшим практикам UX.

## Расположение файла

```
src/app/not-found.tsx
```

Файл создан в корне `app/` директории в соответствии с требованиями Next.js App Router.

## Технические особенности

### Архитектура

- **Client Component** (`"use client"`) — использует интерактивные возможности (навигация назад)
- **TypeScript strict mode** — полная типизация без `any`
- Соответствует FSD архитектуре проекта
- Использует существующие UI компоненты из `@shared/ui`

### Использованные компоненты

1. **Surface** — glass-панель с backdrop-filter для основного контента
2. **Button** — для кнопки "Назад"
3. **buttonStyles** — для стилизации Link компонентов как кнопок
4. **Next.js Link** — для навигации без перезагрузки страницы
5. **Next.js useRouter** — для программной навигации назад

### Дизайн-система

#### Цветовая палитра

- **Brand colors** — оранжевый градиент (#f97316)
- **Accent colors** — фиолетовый (#8b5cf6)
- **Neutral colors** — серые оттенки для текста и фона
- **Background** — использует глобальный фон проекта (#faf9f7)

#### Визуальные эффекты

1. **Декоративные градиенты** — два круга с radial-gradient для атмосферы
2. **Glass-эффект** — backdrop-filter для полупрозрачной панели
3. **Анимации**:
   - `animate-fade-in-up` — появление карточки снизу
   - `animate-scale-in` — масштабирование цифры 404
   - `animate-fade-in` — плавное появление элементов
   - `animate-float` — плавающая анимация иконки поиска
4. **Stagger delays** — элементы появляются последовательно с задержкой
5. **Text gradient** — градиент на цифре 404

## Паттерны и best practices

### Link + buttonStyles паттерн

Вместо оборачивания Button в Link используется прямой подход:

```tsx
<Link
  href="/"
  className={buttonStyles({ variant: "primary", size: "lg" })}
>
  <Home className="h-5 w-5" />
  <span>На главную</span>
</Link>
```

Это соответствует паттерну, используемому в проекте (см. `landing-hero.tsx`).

### Избегание useEffect

Компонент не использует `useEffect` — вся навигация выполняется через обработчики событий, что соответствует правилам проекта.

### Декларативная анимация

Анимации применяются через Tailwind классы, без императивного JS.

## Технические детали

### Навигация "Назад"

```tsx
const handleGoBack = (): void => {
  router.back();
};
```

Использует `router.back()` из Next.js для возврата на предыдущую страницу в истории браузера.

### Декоративные элементы

Градиентные круги и иконка поиска добавляют визуальный интерес, не перегружая UI:

- Круги используют `pointer-events-none` для избежания блокировки кликов
- Непрозрачность и blur создают мягкий эффект
- Иконка поиска в glass-панели намекает на возможность поиска

## Интеграция с проектом

### Автоматическое отображение

Next.js автоматически отображает `not-found.tsx` когда:
- URL не соответствует ни одному роуту
- Вызывается функция `notFound()` в Server Component

### Глобальные стили

Страница использует:
- CSS-переменные из `globals.css`
- Tailwind утилиты
- Custom классы `.glass-panel`, `.text-gradient`, `.animate-*`
