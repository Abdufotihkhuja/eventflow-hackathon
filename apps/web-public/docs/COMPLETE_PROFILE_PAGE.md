# Complete Profile Page - OAuth Onboarding

**Дата:** 2026-01-15  
**Статус:** ✅ Implemented

## Обзор

Страница `/complete-profile` - это финальный шаг онбординга для новых пользователей, которые зарегистрировались через OAuth (Google/LinkedIn). На этой странице пользователь заполняет обязательные поля профиля.

## Проблема

После выбора роли "user" в `/select-role` пользователи сразу попадали в `/profile`, но у них не было заполнено имя и другие обязательные поля. Это приводило к:
- Неполным профилям
- Плохому UX (пользователь не понимал, что делать дальше)
- Отсутствию явного завершения онбординга

## Решение

Создана промежуточная страница `/complete-profile`, которая:
1. Показывается после выбора роли "user"
2. Запрашивает обязательные поля (имя, фамилия)
3. Опционально запрашивает дополнительные поля (телефон, город)
4. Обновляет профиль через API
5. Перенаправляет в `/profile` после успешного сохранения

## OAuth Onboarding Flow

### Полный путь нового пользователя

```
1. Пользователь нажимает "Войти через Google/LinkedIn"
   ↓
2. OAuth авторизация на стороне провайдера
   ↓
3. Backend устанавливает HttpOnly-cookie session и редиректит на:
   /auth/callback?oauth=success&isNewUser=true&isOnboardingCompleted=false
   ↓
4. Frontend bootstrap-ит CSRF и live session
   ↓
5. Редирект на /select-role (выбор роли)
   ↓
6. Пользователь выбирает "Я участник мероприятий"
   ↓
7. Редирект на /complete-profile ← НОВЫЙ ШАГ
   ↓
8. Пользователь заполняет имя, фамилию (обязательно)
   ↓
9. Опционально: телефон, город
   ↓
10. Нажимает "Завершить регистрацию"
    ↓
11. API: PATCH /api/v1/account/me (обновление профиля)
    ↓
12. Редирект на /profile ✅
```

### Обязательные поля

| Поле | Тип | Валидация | Описание |
|------|-----|-----------|----------|
| `firstName` | string | 2-50 символов | Имя пользователя |
| `lastName` | string | 2-50 символов | Фамилия пользователя |

### Опциональные поля

| Поле | Тип | Валидация | Описание |
|------|-----|-----------|----------|
| `phone` | string | min 10 символов | Номер телефона |
| `location` | string | - | Город проживания |

## Валидация (Zod Schema)

```typescript
const completeProfileSchema = z.object({
  firstName: z
    .string()
    .min(2, "Имя должно содержать минимум 2 символа")
    .max(50, "Имя не должно превышать 50 символов"),
  lastName: z
    .string()
    .min(2, "Фамилия должна содержать минимум 2 символа")
    .max(50, "Фамилия не должна превышать 50 символов"),
  phone: z
    .string()
    .min(10, "Введите корректный номер телефона")
    .optional()
    .or(z.literal("")),
  location: z.string().optional().or(z.literal("")),
});
```

## API Integration

### Endpoint

```
PATCH /api/v1/account/me
```

### Request Body

```typescript
{
  name: "Иван Иванов",  // firstName + lastName
  phone: "+998901234567",  // опционально
  location: "Ташкент, Узбекистан"  // опционально
}
```

### Response

```typescript
{
  id: "uuid",
  email: "user@example.com",
  name: "Иван Иванов",
  phone: "+998901234567",
  location: "Ташкент, Узбекистан",
  // ... другие поля
}
```

## Обработка ошибок

### Валидация на клиенте

```typescript
// Показывается под полем
{errors.firstName && (
  <p className="text-sm font-medium text-red-600" role="alert">
    {errors.firstName.message}
  </p>
)}
```

### Ошибки API

```typescript
// Показывается в карточке над кнопкой
{error && (
  <div className="rounded-xl border border-red-200 bg-red-50 p-4">
    <p className="text-sm font-medium text-red-800">{error}</p>
  </div>
)}
```

### Типичные ошибки

| Ошибка | Причина | Решение |
|--------|---------|---------|
| "Имя должно содержать минимум 2 символа" | Короткое имя | Ввести минимум 2 символа |
| "Ошибка при обновлении профиля" | Проблема с API | Попробовать еще раз |
| 401 Unauthorized | Токен истек | Перелогиниться |
| 500 Server Error | Проблема на backend | Сообщить в поддержку |
