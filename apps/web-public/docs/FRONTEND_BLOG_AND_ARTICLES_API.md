# Блог и «сохранённые статьи» — API для Frontend

Документ разделяет два разных понятия и описывает все связанные эндпоинты, чтобы на фронте не путать источники данных.

---

## 1. Различие понятий

| Понятие                                        | Что это                                                                                                    | Где хранится                                     | Для чего                                                                               |
| ---------------------------------------------- | ---------------------------------------------------------------------------------------------------------- | ------------------------------------------------ | -------------------------------------------------------------------------------------- |
| **Блог (Blog Post)**                           | Статья блога **платформы EventFlow**: создаётся организатором, контент в БД, есть slug, организация, теги. | Таблица `BlogPost`                               | Публичный блог на сайте (лента статей, страница статьи).                               |
| **Сохранённые посты блога (Saved Blog Posts)** | Факт: «пользователь сохранил пост блога EventFlow». Привязка по **ID поста**.                              | Таблица `SavedBlogPost` (userId + postId)        | Кнопка «Сохранить» на странице поста блога, раздел «Мои сохранённые посты блога».      |
| **Сохранённые статьи по URL (Saved Articles)** | Закладка на **любую статью по ссылке** (любой сайт). Сохраняется URL + метаданные (title, excerpt и т.д.). | Таблица `SavedArticle` (userId + articleUrl + …) | Функция «сохранить статью в закладки» (read-it-later), в т.ч. ссылки на внешние сайты. |

**Важно для фронта:**

- Для **постов блога EventFlow** (страница блога, карточка поста, кнопка «Сохранить» на посте) используйте только **Saved Blog Posts** (`/account/me/saved-blog-posts`).
- Для **закладок по URL** (произвольные ссылки, не привязанные к посту по id) используйте только **Saved Articles** (`/account/me/articles`).
- Поле `saved` в ответах публичного блога считается **только** из Saved Blog Posts.

---

## 2. Публичный блог (чтение постов)

Базовый путь: **`GET /api/v1/blog`**. Авторизация не обязательна; при переданном JWT в ответ добавляется поле `saved` для пользователей с типом `USER`.

### 2.1. Список опубликованных постов

```http
GET /api/v1/blog?page=1&limit=10&search=...&organizationId=...&tagId=...&tagIds[]=...&publishedAfter=...&publishedBefore=...&minReadingTime=...&maxReadingTime=...&sortBy=...&sortOrder=...
```

**Query (все опциональны):**

| Параметр          | Тип      | Описание                                                                       |
| ----------------- | -------- | ------------------------------------------------------------------------------ |
| `page`            | number   | Номер страницы (по умолчанию 1).                                               |
| `limit`           | number   | Записей на странице.                                                           |
| `search`          | string   | Поиск по заголовку и краткому описанию.                                        |
| `organizationId`  | UUID     | Фильтр по организации.                                                         |
| `tagId`           | UUID     | Один тег.                                                                      |
| `tagIds`          | UUID[]   | Несколько тегов (статья с любым из).                                           |
| `publishedAfter`  | ISO 8601 | Опубликовано после.                                                            |
| `publishedBefore` | ISO 8601 | Опубликовано до.                                                               |
| `minReadingTime`  | number   | Мин. время чтения (мин).                                                       |
| `maxReadingTime`  | number   | Макс. время чтения (мин).                                                      |
| `sortBy`          | enum     | `createdAt` \| `publishedAt` \| `likesCount` \| `viewsCount` \| `readingTime`. |
| `sortOrder`       | enum     | `asc` \| `desc`.                                                               |

**Заголовок (опционально):**  
`Authorization: Bearer <access_token>` — для пользователя типа USER в каждую запись добавляется **`saved: boolean`**.

**Ответ 200:**  
Стандартная пагинация: `{ data: BlogPost[], total, page, limit, totalPages }`. У каждого элемента при наличии JWT — поле **`saved`**.

---

### 2.2. Один пост по slug

```http
GET /api/v1/blog/by-slug/:slug
```

**Параметр:** `slug` — URL-slug поста (например из пути страницы).

**Заголовок (опционально):**  
`Authorization: Bearer <access_token>` — в ответ добавляется **`saved: boolean`**.

**Ответ 200:** объект поста блога; при JWT — с полем **`saved`**.  
**404** — пост не найден или не опубликован.

---

### 2.3. Один пост по ID

```http
GET /api/v1/blog/:id
```

**Параметр:** `id` — UUID поста.

**Заголовок (опционально):**  
`Authorization: Bearer <access_token>` — в ответ добавляется **`saved: boolean`**.

**Ответ 200:** объект поста; при JWT — с полем **`saved`**.  
**404** — пост не найден или не опубликован.

---

## 3. Сохранённые посты блога (Saved Blog Posts)

Базовый путь: **`/api/v1/account/me/saved-blog-posts`**.  
Все методы требуют авторизации и роль **USER** (`Authorization: Bearer <access_token>`).

Используйте эти эндпоинты для:

- кнопки «Сохранить / Убрать из сохранённых» на странице поста блога EventFlow;
- раздела «Мои сохранённые посты блога» (список сохранённых постов).

### 3.1. Список сохранённых постов блога

```http
GET /api/v1/account/me/saved-blog-posts?page=1&limit=10
```

**Query (опционально):**

| Параметр | Тип    | Описание                                     |
| -------- | ------ | -------------------------------------------- |
| `page`   | number | Страница (по умолчанию 1).                   |
| `limit`  | number | Записей на странице (1–50, по умолчанию 10). |

**Ответ 200:**  
`{ data, total, page, limit, totalPages }`. В `data` — записи с вложенным объектом **`post`** (полный пост блога: организация, теги и т.д.). В списке только посты со статусом «опубликован».

---

### 3.2. Сохранить пост блога

```http
POST /api/v1/account/me/saved-blog-posts/:postId
```

**Параметр:** `postId` — UUID поста блога (из `GET /api/v1/blog` или `GET /api/v1/blog/by-slug/:slug`).

**Ответ 201:** созданная запись SavedBlogPost (в т.ч. с `post`).  
**409** — пост уже сохранён.

---

### 3.3. Удалить пост из сохранённых

```http
DELETE /api/v1/account/me/saved-blog-posts/:postId
```

**Параметр:** `postId` — UUID поста.

**Ответ 200:** успех.  
**409** — пост не был в сохранённых.

---

### 3.4. Проверить, сохранён ли пост

```http
GET /api/v1/account/me/saved-blog-posts/:postId/check
```

**Параметр:** `postId` — UUID поста.

**Ответ 200:** `{ saved: boolean }`.

---

## 4. Сохранённые статьи по URL (Saved Articles)

Базовый путь: **`/api/v1/account/me/articles`**.  
Все методы требуют авторизации и роль **USER**.

Используйте для:

- «Сохранить в закладки» по ссылке (в т.ч. внешние сайты);
- раздела «Мои сохранённые статьи» (список закладок по URL).

**Не используйте** эти эндпоинты для кнопки «Сохранить» на постах блога EventFlow — для этого только Saved Blog Posts (раздел 3).

### 4.1. Список сохранённых статей (закладок по URL)

```http
GET /api/v1/account/me/articles?page=1&limit=12&search=...&category=...
```

**Query (все опциональны):**

| Параметр   | Тип    | Описание                                      |
| ---------- | ------ | --------------------------------------------- |
| `page`     | number | Страница (по умолчанию 1).                    |
| `limit`    | number | Записей на странице (1–100, по умолчанию 12). |
| `search`   | string | Поиск по заголовку и описанию.                |
| `category` | string | Фильтр по категории (например `TIPS-GUIDES`). |

**Ответ 200:**  
`{ total, page, limit, articles: SavedArticleResponseDto[] }`.  
Каждый элемент: `id`, `slug` (извлечён из URL), `articleUrl`, `title`, `excerpt`, `coverImage`, `category`, `publishedAt`, `readingTime`, `authorName`, `savedAt`.

---

### 4.2. Сохранить статью по URL

```http
POST /api/v1/account/me/articles
Content-Type: application/json
```

**Body (SaveArticleDto):**

| Поле          | Тип               | Обязательное | Описание                         |
| ------------- | ----------------- | ------------ | -------------------------------- |
| `articleUrl`  | string (URL)      | да           | Ссылка на статью (любой домен).  |
| `title`       | string (max 500)  | да           | Заголовок.                       |
| `excerpt`     | string (max 2000) | нет          | Краткое описание.                |
| `coverImage`  | string (URL)      | нет          | URL обложки.                     |
| `category`    | string (max 100)  | нет          | Категория (напр. `TIPS-GUIDES`). |
| `publishedAt` | string (ISO 8601) | нет          | Дата публикации.                 |
| `readingTime` | number (1–120)    | нет          | Время чтения в минутах.          |
| `authorName`  | string (max 200)  | нет          | Имя автора.                      |

**Ответ 201:** созданная запись SavedArticle.  
**409** — статья с таким URL уже сохранена у пользователя.

---

### 4.3. Проверить, сохранена ли статья по URL

```http
GET /api/v1/account/me/articles/check?url=<encoded_article_url>
```

**Query:** `url` — полный URL статьи (должен совпадать с сохранённым).

**Ответ 200:** `{ saved: boolean }`.

---

### 4.4. Удалить из сохранённых по ID записи

```http
DELETE /api/v1/account/me/articles/:id
```

**Параметр:** `id` — UUID записи в SavedArticle (из ответа списка или создания).

**Ответ 204:** успех.

---

### 4.5. Удалить из сохранённых по URL

```http
DELETE /api/v1/account/me/articles?url=<encoded_article_url>
```

**Query:** `url` — полный URL статьи.

**Ответ 204:** успех.  
**404** — такой статьи в сохранённых нет.

---

## 5. Сводная таблица: когда какой API

| Сценарий на фронте                                 | API                                                                                                                       |
| -------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------- |
| Лента постов блога (главная блога, фильтры)        | `GET /api/v1/blog` (опционально с JWT для `saved`)                                                                        |
| Страница одной статьи блога по slug                | `GET /api/v1/blog/by-slug/:slug` (опционально с JWT для `saved`)                                                          |
| Кнопка «Сохранить» на посте блога EventFlow        | `POST /api/v1/account/me/saved-blog-posts/:postId`                                                                        |
| Кнопка «Убрать из сохранённых» на посте блога      | `DELETE /api/v1/account/me/saved-blog-posts/:postId`                                                                      |
| Раздел «Мои сохранённые посты блога»               | `GET /api/v1/account/me/saved-blog-posts`                                                                                 |
| Узнать, сохранён ли пост блога (для иконки)        | `GET /api/v1/account/me/saved-blog-posts/:postId/check` или поле `saved` в ответе `GET /blog` / `GET /blog/by-slug/:slug` |
| Сохранить произвольную статью по ссылке (закладка) | `POST /api/v1/account/me/articles`                                                                                        |
| Раздел «Мои сохранённые статьи» (закладки по URL)  | `GET /api/v1/account/me/articles`                                                                                         |
| Удалить закладку по URL                            | `DELETE /api/v1/account/me/articles` или `DELETE /api/v1/account/me/articles/:id`                                         |

---

## 6. Кратко

- **Блог** — контент платформы: читать через **`/api/v1/blog`**; при JWT в ответах есть **`saved`** (из Saved Blog Posts).
- **Сохранённые посты блога** — только **`/api/v1/account/me/saved-blog-posts`** (сохранить/удалить/список/check). Один источник правды для «сохранённого» по постам блога.
- **Сохранённые статьи по URL** — только **`/api/v1/account/me/articles`** (закладки по ссылке, любой сайт). С блогом по контенту не смешивать.
