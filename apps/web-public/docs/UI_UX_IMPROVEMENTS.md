# Улучшения UI/UX лендинга (февраль 2026)

Краткое описание внесённых изменений в соответствии с лучшими практиками и требованиями доступности.

## Доступность (a11y)

- **Skip-link**: ссылка «Перейти к контенту» с классом `sr-only` — визуально скрыта, доступна скринридерам, ведёт к `#main-content`.
- **Main**: у `<main>` заданы `id="main-content"` и `tabIndex={-1}` для приёма фокуса после перехода по skip-link.
- **Focus-visible**: у интерактивных элементов (кнопки, ссылки, дропдауны, карточки-ссылки) единый фокус-стиль: кольцо `ring-2 ring-brand-500 ring-offset-2`.
- **Touch targets**: минимальный размер кликабельной области ~44px (кнопка региона, быстрые категории в Hero, мобильное меню, навигация слайдера подборок, пункты навигации в хедере).
- **Reduced motion**: в `globals.css` добавлен `@media (prefers-reduced-motion: reduce)` — анимации и переходы сводятся к минимуму при включённой настройке в ОС.

## Типографика и визуальная иерархия

- **Заголовки**: в базовом слое заданы fluid-размеры для `h1` (clamp) и `h2`; Hero использует общий стиль без дублирования жёстких размеров.
- **Подзаголовок Hero**: добавлен `text-balance` для лучшего переноса строк.

## Компоненты

- **Hero**: фокус-стили для выбора региона, поиска и быстрых категорий; подпись «Популярные категории» с чуть более контрастным цветом (`text-neutral-500`).
- **Карточки событий**: `focus-within` — при фокусе на ссылке внутри карточки визуально выделяется вся карточка (граница и тень).
- **Категории и подборки**: у ссылок-карточек и заголовков секций добавлен `focus-visible` ring.
- **Хедер**: фокус и увеличенная область нажатия у пунктов навигации и дропдаунов; мобильная кнопка меню не менее 44×44px.
- **Футер**: фокус-стили у всех ссылок (навигация, конфиденциальность, условия, cookies).
- **Кнопки навигации слайдера подборок**: размер не менее 44px и фокус-кольцо.

## Контейнер и глобальные стили

- **Container**: `max-width` увеличен с 1200px до 1280px для более комфортной ширины на больших экранах.
- **Transition**: длительность hover на карточке события уменьшена с 500ms до 300ms для более отзывчивого ощущения.

## Рекомендации для дальнейших правок

- Сохранять единый стиль фокуса (`focus-visible:ring-2 ring-brand-500 ring-offset-2`) для всех интерактивных элементов.
- Новые кликабельные элементы делать не менее 44×44px (или с достаточным padding).
- Не полагаться только на цвет для передачи состояния; дублировать индикацию формой/рамкой/иконкой где нужно.
