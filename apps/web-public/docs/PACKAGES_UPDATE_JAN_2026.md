## Критические изменения

### 1. Zod: откат с 4.x на 3.x

**Проблема:** В `package.json` была указана версия `zod: ^4.1.12`, которая не существует.

**Решение:** Откат на актуальную версию `3.24.1`.

**Изменения в коде:**

- Файл: `src/features/auth/signup/model/schema.ts`
- Изменено: `z.discriminatedUnion()` → `z.union()`
- Причина: В Zod 3.x `discriminatedUnion` имеет другую типизацию

```typescript
// Было (некорректно для Zod 3.x):
export const signupSchema = z.discriminatedUnion("accountType", [
  userSignupSchema,
  organizerSignupSchema,
]);

// Стало:
export const signupSchema = z.union([userSignupSchema, organizerSignupSchema]);
```

### 2. Next.js: откат с 16.x на 15.x

**Проблема:** Next.js 16.x находится в статусе канарейки (нестабильная версия).

**Решение:** Использование стабильной версии 15.5.9.

**Преимущества:**

- Стабильность в production
- Полная совместимость с экосистемой
- Отсутствие breaking changes

### 3. ESLint: обновление конфигурации

**Проблема:** Новая версия `eslint-config-next` изменила формат экспорта модулей.

**Решение:** Использование `FlatCompat` для обратной совместимости.

**Изменения в `eslint.config.mjs`:**

```javascript
// Добавлены импорты:
import { FlatCompat } from "@eslint/eslintrc";
import js from "@eslint/js";

// Изменен способ подключения конфигов Next.js:
const compat = new FlatCompat({
  baseDirectory: __dirname,
  recommendedConfig: js.configs.recommended,
});

const eslintConfig = [
  ...compat.extends("next/core-web-vitals", "next/typescript"),
  // ... остальная конфигурация
];
```

### 4. TypeScript: автоматическая настройка

Next.js автоматически обновил `tsconfig.json`:

- `jsx` установлен в `preserve` (оптимизированная трансформация JSX)
