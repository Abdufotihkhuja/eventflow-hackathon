# Реализация билетов и QR-кодов для событий

## Обзор

Реализована функциональность просмотра и скачивания билетов для зарегистрированных пользователей с улучшенным UI/UX и мобильной адаптацией.

## Изменения в API

### Добавлено в `registrationService.ts`

```typescript
/**
 * Скачать билет регистрации в формате PDF
 * GET /api/v1/registrations/{id}/ticket?design={design}
 */
downloadTicket: (
  registrationId: string,
  design: "branded" | "simple" = "branded"
): string
```

Метод генерирует URL для скачивания билета с авторизацией через токен.

## Новые компоненты

### TicketCardModal

**Путь:** `src/widgets/profile/ticket-card/ui/ticket-card-modal.tsx`

Компонент модального окна для отображения электронного билета пользователя.

#### Основные возможности:

1. **Отображение QR-кода** 
   - Загрузка через API `/api/v1/registrations/{id}/qr`
   - Fallback на QR из данных события
   - Индикация загрузки

2. **Детальная информация о событии**
   - Дата и время
   - Место проведения и адрес
   - Организатор
   - Роль участника (Участник/Спикер/Ментор)
   - Номер билета

3. **Скачивание билетов в PDF**
   - Два дизайна: **Фирменный** (branded) и **Простой** (simple)
   - Выбор дизайна перед скачиванием
   - Индикация процесса загрузки

4. **Быстрые действия**
   - **Добавить в календарь** - интеграция с Google Calendar
   - **Поделиться** - Web Share API для мобильных устройств
   - Fallback на копирование ссылки в буфер обмена

5. **Мобильная оптимизация**
   - Responsive дизайн
   - Touch-friendly интерфейс
   - Адаптивная сетка элементов
   - Оптимизированные размеры для смартфонов
   - Поддержка Web Share API на мобильных

#### Дизайн особенности:

- **Градиентный хедер** с брендовыми цветами
- **Карточная компоновка** информации
- **Визуальные иконки** для каждого типа данных
- **Цветовое кодирование** ролей участника
- **Анимации** появления/исчезновения
- **Backdrop blur** для фона модала

## UX улучшения

### Для мобильных устройств:

1. **Адаптивная сетка** - 2 колонки на малых экранах, flex на больших
2. **Оптимизированные отступы** - комфортные для касаний
3. **Читаемый шрифт** - размеры от 10px до 24px
4. **Крупные touch-таргеты** - минимум 44x44px для кнопок
5. **Backdrop blur** - улучшает читаемость на любом фоне

### Визуальная иерархия:

1. **Акцент на QR-коде** - центральное расположение, крупный размер
2. **Группировка информации** - карточки для каждого типа данных
3. **Цветовые индикаторы** - разные цвета для разных типов информации
4. **Иконки** - быстрое визуальное распознавание типа данных

### Интерактивность:

1. **Выбор дизайна билета** - toggle между branded/simple
2. **Анимация загрузки** - spinner при скачивании
3. **Добавление в календарь** - одним кликом в Google Calendar
4. **Социальный шеринг** - Web Share API или копирование ссылки
5. **Информационные подсказки** - подсказка о сохранении билета
6. **Закрытие модала** - клик вне области или на крестик

## API endpoints используемые

1. `GET /api/v1/registrations/{id}/qr` - получение QR-кода
2. `GET /api/v1/registrations/{id}/ticket?design={design}` - скачивание билета

## Поддерживаемые статусы

Билет доступен для регистраций со статусами:
- `APPROVED` - подтверждённые регистрации
- `ATTENDED` - посещённые события

## Типы дизайнов билетов

1. **Branded** (фирменный)
   - Корпоративный стиль организации
   - Полная брендированная версия
   - По умолчанию

2. **Simple** (простой)
   - Минималистичный дизайн
   - Базовая информация
   - Меньший размер файла

## Технические детали

### Зависимости:
- `@tanstack/react-query` - для кеширования QR-кода
- `lucide-react` - иконки
- `next/image` - оптимизация изображений
- TailwindCSS - стилизация

### Оптимизации:
- Lazy loading QR-кода
- Кеширование данных билета (5 минут)
- Fallback для QR из данных события
- Предотвращение множественных кликов при скачивании
- Прогрессивное улучшение (Web Share API с fallback)
- Автоматический расчет времени окончания события (+2 часа)
