# Руководство: Каталог прошедших событий

## Быстрый старт

### 1. Открыть каталог прошедших событий

Перейдите по адресу:
```
/events/past
```

Или нажмите кнопку **"Архив прошедших событий →"** на странице `/events`

### 2. Использование поиска

В строке поиска введите запрос:
- Название события
- Категорию (хакатон, конференция)
- Формат (онлайн, офлайн)
- Город
- Любое ключевое слово

**Пример:**
```
офлайн хакатон сертификат
```

### 3. Применение фильтров

Нажмите на кнопки фильтров для уточнения результатов:

- **Онлайн и гибрид** - только онлайн/гибридные события
- **Офлайн-площадки** - события с физическим присутствием
- **С сертификатом участия** - события с сертификатами
- **Командные и индивидуальные** - разрешающие групповую регистрацию
- **Безлимит или с лимитом мест** - без ограничений по количеству
- **Открытые и по приглашению** - открытые для всех
- **Бесплатные и платные** - платные мероприятия

**Комбинирование:**
Можно активировать несколько фильтров одновременно для точного поиска.

### 4. Просмотр деталей события

Нажмите на карточку события, чтобы увидеть:
- Полное описание
- Программу мероприятия
- Спикеров
- Фотогалерею (если доступна)
- Материалы и результаты

## API параметры

### Получение прошедших событий

```typescript
import { eventService } from "@shared/api/eventService";

// Базовый запрос
const response = await eventService.getPublicEvents({
  filter: "past",
  limit: 50
});

// С дополнительными фильтрами
const filtered = await eventService.getPublicEvents({
  filter: "past",
  city: "Tashkent",
  format: "OFFLINE",
  type: "FREE"
});
```

### Параметры фильтрации

| Параметр | Тип | Значения | Описание |
|----------|-----|----------|----------|
| `filter` | string | `upcoming`, `past`, `all` | Фильтр по времени события |
| `city` | string | Любой город | Город проведения |
| `format` | string | `ONLINE`, `OFFLINE`, `HYBRID` | Формат мероприятия |
| `type` | string | `FREE`, `PAID` | Тип оплаты |
| `search` | string | Любой текст | Поиск по названию |
| `page` | number | >= 1 | Номер страницы |
| `limit` | number | 1-100 | Записей на странице |

## Программное использование

### В React-компонентах

```tsx
import { usePublicEventsQuery } from "@shared/lib/hooks";

function MyComponent() {
  const { data, isLoading, error } = usePublicEventsQuery({
    params: {
      filter: "past",
      limit: 20
    }
  });

  if (isLoading) return <div>Загрузка...</div>;
  if (error) return <div>Ошибка: {error.message}</div>;

  return (
    <div>
      {data.data.map(event => (
        <div key={event.id}>{event.title}</div>
      ))}
    </div>
  );
}
```

### Навигация между страницами

```tsx
import Link from "next/link";
import { useRouter } from "next/navigation";

// Через Link
<Link href="/events/past">Архив событий</Link>

// Через Router
const router = useRouter();
router.push("/events/past");
```

## Часто задаваемые вопросы

### Как отличить прошедшие события от предстоящих?

**Визуально:**
- Прошедшие события: фиолетовая цветовая схема в Hero-секции
- Предстоящие события: оранжево-жёлтая цветовая схема

**Программно:**
```typescript
// По URL
const isPastEventsPage = pathname === "/events/past";

// По параметру filter
const { data } = usePublicEventsQuery({
  params: { filter: "past" }
});
```

### Можно ли комбинировать поиск и фильтры?

Да, система поддерживает одновременное использование:
1. Текстового поиска
2. Временных фильтров (past/upcoming/all)
3. Фильтров по формату, городу, типу оплаты
4. Клиентских фильтров (UI-кнопки)

### Где хранятся фильтры?

- **API-фильтры** (`filter`, `city`, `format`, `type`) отправляются на сервер
- **Клиентские фильтры** (UI-кнопки) работают локально после получения данных
- Состояние фильтров сбрасывается при перезагрузке страницы

### Как добавить фильтр в URL?

```tsx
// Текущая реализация использует query params только для search
router.push("/events/past?query=хакатон");

// Для сохранения всех фильтров в URL потребуется дополнительная разработка
```

## Производительность

### Оптимизация запросов

```typescript

  params: { filter: "past" },
  staleTime: 15 * 60 * 1000 // 15 минут
});
```

## Troubleshooting

### События не загружаются

1. Проверьте консоль браузера на ошибки
2. Убедитесь, что API доступен
3. Проверьте переменные окружения (`VITE_API_URL`)

### Фильтры не работают

1. Проверьте, что выбранные фильтры корректны
2. Убедитесь, что в БД есть события, соответствующие фильтрам
3. Проверьте network tab - запрос должен содержать query-параметры

### Медленная загрузка

1. Уменьшите `limit` в параметрах запроса
2. Включите пагинацию (будущая фича)
3. Используйте lazy loading для изображений
