# Программа мероприятия - Финальная версия

## Дата: 21.01.2026

## 🎉 Реализованные функции

### ✅ Основные возможности

1. **Drag & Drop изменение порядка**
   - Перетаскивание элементов мышью
   - Клавиатурная навигация (пробел + стрелки)
   - Визуальная индикация при перетаскивании
   - Автоматическое сохранение нового порядка

2. **Полная информация о пункте программы**
   - Название (обязательно)
   - Описание (опционально)
   - Тип активности (6 типов)
   - Время начала и длительность
   - Место проведения (опционально)
   - **Спикеры** (multi-select из спикеров события)
   - **Материалы** (список ссылок)

3. **UX улучшения**
   - Цветные иконки для каждого типа
   - Badge с информацией о спикерах
   - Компактное отображение с раскрытием
   - Inline редактирование
   - Toast уведомления
   - Подтверждение удаления

### 🎯 Структура данных

```typescript
type AgendaItem = {
  id: string
  eventId: string
  title: string                           // Обязательно
  description: string | null              // Опционально
  type: AgendaItemType                    // Обязательно
  startTime: string                       // ISO datetime
  duration: number                        // В минутах
  location: string | null                 // Опционально
  materials: string[]                     // Массив ссылок
  sortOrder: number                       // Управляется автоматически
  speakers: Array<{ id: string; name: string }>
  createdAt: string
  updatedAt: string
}
```

## 🚀 Использование

### Добавление пункта программы

1. Нажмите **"Добавить пункт"**
2. Заполните обязательные поля:
   - **Название** - краткое название активности
   - **Тип** - выберите тип из списка
   - **Время начала** - HH:MM формат
   - **Длительность** - количество минут (минимум 1)

3. Заполните опциональные поля:
   - **Описание** - подробное описание активности
   - **Место** - где будет проходить (например: "Главный зал")
   - **Спикеры** - выберите одного или нескольких спикеров
   - **Материалы** - добавьте ссылки на презентации/документы (по одной на строку)

4. Нажмите **"Сохранить"**

### Изменение порядка элементов

**Способ 1: Drag & Drop (мышь)**
1. Наведите на иконку ⋮⋮ (слева от элемента)
2. Зажмите левую кнопку мыши
3. Перетащите элемент на новое место
4. Отпустите кнопку мыши
5. Порядок автоматически сохранится

**Способ 2: Клавиатура**
1. Переместите фокус на элемент (Tab)
2. Нажмите **Пробел** для захвата
3. Используйте **↑/↓** для перемещения
4. Нажмите **Пробел** для отпускания

### Редактирование пункта

1. Кликните на карточку пункта для раскрытия
2. Нажмите **"Редактировать"**
3. Измените нужные поля
4. Нажмите **"Сохранить"** или **"Отмена"**

### Добавление спикеров

1. В режиме редактирования найдите секцию "Спикеры"
2. Отметьте галочками нужных спикеров
3. Можно выбрать одного или нескольких
4. Счётчик показывает количество выбранных

**Примечание:** Спикеры должны быть предварительно добавлены на вкладке "Спикеры"

### Добавление материалов

1. В режиме редактирования найдите поле "Материалы"
2. Введите ссылки на материалы (по одной на строку):
   ```
   https://example.com/presentation.pdf
   https://example.com/handout.docx
   https://drive.google.com/file/...
   ```
3. Материалы будут отображаться как кликабельные ссылки

### Удаление пункта

1. Раскройте карточку пункта
2. Нажмите кнопку с иконкой корзины (🗑️)
3. Подтвердите удаление в диалоге

## 💡 Полезные советы

### Планирование времени

- **Вычисляемое время окончания** - отображается автоматически
- **Сортировка** - элементы автоматически сортируются по времени начала
- **Длительность** - используйте шаг 5 минут для удобства

### Организация программы

1. **Используйте типы активностей** для визуального разделения
   - KEYNOTE - для главных докладов
   - BREAK - для перерывов (кофе-брейк, обед)
   - WORKSHOP - для практических занятий
   - NETWORKING - для свободного общения

2. **Добавляйте описания** для важных сессий
   - Что будет обсуждаться
   - Какие темы будут затронуты
   - Что участники узнают

3. **Указывайте место проведения** для больших событий
   - "Зал A", "Зал B" и т.д.
   - Помогает участникам ориентироваться

4. **Прикрепляйте материалы** заранее
   - Презентации
   - Раздаточные материалы
   - Дополнительные ресурсы

### Работа со спикерами

- Сначала добавьте спикеров на вкладке "Спикеры"
- Один спикер может вести несколько сессий
- В программе будет показан список спикеров для каждой сессии

## 🔧 Технические детали

### API запросы

**Создание пункта:**
```typescript
POST /api/v1/events/{eventId}/agenda
{
  "title": "Открытие конференции",
  "description": "Торжественное открытие",
  "type": "KEYNOTE",
  "startTime": "1970-01-01T09:00:00.000Z",
  "duration": 60,
  "location": "Главный зал",
  "materials": [
    "https://example.com/presentation.pdf"
  ],
  "speakerIds": ["uuid1", "uuid2"],
  "sortOrder": 1
}
```

**Изменение порядка:**
```typescript
PATCH /api/v1/events/{eventId}/agenda/reorder
{
  "itemIds": ["uuid1", "uuid2", "uuid3", ...]
}
```

### Drag & Drop библиотека

Используется **@dnd-kit** для реализации drag & drop:
- `@dnd-kit/core` - основная функциональность
- `@dnd-kit/sortable` - для сортируемых списков
- `@dnd-kit/utilities` - утилиты

**Преимущества:**
- ✅ Поддержка клавиатуры (accessibility)
- ✅ Touch-friendly (работает на мобильных)
- ✅ Производительность
- ✅ TypeScript support

### Автоматическая сортировка

Элементы автоматически сортируются по:
1. **Времени начала** (startTime) - первичная сортировка
2. **sortOrder** - вторичная сортировка (для элементов с одинаковым временем)

### Конвертация времени

**Frontend ↔ Backend:**
```typescript
// Пользователь вводит: "12:30"
// Frontend конвертирует в: "1970-01-01T12:30:00.000Z"
// Backend сохраняет: "1970-01-01T12:30:00.000Z"
// Frontend показывает: "12:30"
```

## ⚠️ Валидация и ограничения

### Обязательные поля
- ❌ Название не может быть пустым
- ❌ Длительность минимум 1 минута
- ❌ Тип активности обязателен

### Опциональные поля
- ✅ Описание может быть пустым
- ✅ Место может быть не указано
- ✅ Можно не выбирать спикеров
- ✅ Материалы опциональны

### Форматы данных
- **Время** - HH:MM (24-часовой формат)
- **Длительность** - целое число минут
- **Материалы** - валидные URL (каждый с новой строки)

## 🐛 Устранение проблем

### Не могу перетащить элемент
- Убедитесь, что элемент не в режиме редактирования
- Захватывайте за иконку ⋮⋮ слева
- Попробуйте использовать клавиатуру (пробел + стрелки)

### Спикеры не отображаются
- Сначала добавьте спикеров на вкладке "Спикеры"
- Обновите страницу
- Проверьте, что спикеры привязаны к событию

### Порядок не сохраняется
- Проверьте подключение к интернету
- Убедитесь, что нет ошибок в консоли
- Обновите страницу и попробуйте снова
