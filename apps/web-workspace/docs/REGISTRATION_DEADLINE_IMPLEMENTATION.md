# Реализация "Дедлайна регистрации" для событий

## Описание
Добавлен функционал "дедлайна регистрации" при создании и редактировании события. Это позволяет организаторам указать время, до которого возможна регистрация участников.

## Внесённые изменения

### 1. API типы (`src/api/services/event.types.ts`)
- Добавлено поле `registrationDeadline?: string` в типе `Event`
- Добавлено поле `registrationDeadline?: string` в типе `CreateEventRequest`
- Поле представляет ISO datetime строку

### 2. Валидация формы (`src/features/events/lib/schemas/create-event-schema.ts`)
- Добавлена валидация поля `registrationDeadline` (опциональное, но если указано - должно быть корректной датой)
- Добавлено правило `refine`: дедлайн регистрации должен быть не позже даты начала события
- Сообщение об ошибке: "Дедлайн регистрации должен быть не позже даты начала события"

### 3. Форма создания события (`src/features/events/ui/create-event-form/create-event-form.tsx`)
- Добавлено новое поле ввода "Дедлайн регистрации" в секцию "Даты проведения"
- Используется `datetime-local` input для удобства
- Отображается описание: "Время, до которого возможна регистрация. Должно быть не позже даты начала события"
- Реструктурирована секция "Даты проведения" для лучшей читаемости:
  - Сетка 2 столбца для startDate и endDate
  - Отдельное поле для registrationDeadline на всю ширину

### 4. Компонент редактирования события (NEW)
- Создан `src/features/events/ui/edit-event-form/edit-event-form.tsx`
- Использует ту же схему валидации, что и создание события
- Заполняет поле `registrationDeadline` из существующего события
- Передает в API только изменённые поля (через `UpdateEventRequest`)
- Отвечает за инвалидирование кеша при успешном обновлении

### 5. Страница редактирования события (`src/pages/my-events/edit/ui/edit-event-page.tsx`)
- Заменена заглушка на реальную форму редактирования
- Используется компонент `EditEventForm` с моковыми данными события
- Сохранён стиль и структура страницы создания события

### 6. Страница детализации события (`src/pages/my-events/details/ui/event-details-page.tsx`)
- Добавлена иконка `Clock` из lucide-react
- Добавлена карточка информации для отображения дедлайна регистрации:
  - Показывает дедлайн, если он указан в событии
  - Заменяет карточку "Тип события", если дедлайн указан
  - Если дедлайн указан, добавляется дополнительная карточка для типа события
- Используется форматирование даты через `date-fns` с локалью `ru`

### 7. Моковые данные (`src/pages/my-events/lib/mock-data.ts`)
- Добавлено поле `registrationDeadline` для первых трёх событий:
  - Событие 1: Дедлайн 10 марта 2025 (начало 15 марта)
  - Событие 2: Дедлайн 8 декабря (начало 10 декабря)
  - Событие 3: Дедлайн 15 февраля (начало 20 февраля)

### 8. Экспорты
- Обновлен `src/features/events/ui/index.ts` - добавлен экспорт `EditEventForm`
- Обновлен `src/features/events/index.ts` - добавлен экспорт `EditEventForm`

## Использование в компоненте

### Создание события
```tsx
import { CreateEventForm } from '@features/events'

export default function CreateEventPage() {
  return <CreateEventForm />
}
```

### Редактирование события
```tsx
import { EditEventForm } from '@features/events'

export default function EditEventPage() {
  const event = getEventData()
  return <EditEventForm event={event} />
}
```

## Валидация

1. **Дата формата**: Проверяется, что введённая дата корректна (через `Date.parse`)
2. **Логика дедлайна**: Дедлайн регистрации ≤ Дата начала события
3. **Опциональность**: Поле не обязательно, но если указано - должно быть корректным

## API контракт

### Запрос создания события
```typescript
{
  title: string
  description: string
  type: EventType
  format: EventFormat
  startDate: string        // ISO datetime
  endDate: string          // ISO datetime
  registrationDeadline?: string  // ISO datetime (опционально)
  // ... остальные поля
}
```

### Ответ события
```typescript
{
  id: string
  title: string
  startDate: string
  endDate: string
  registrationDeadline?: string  // ISO datetime (опционально)
  // ... остальные поля
}
```

## Тестирование

1. Создать событие с дедлайном регистрации - должно успешно сохраниться
2. Отредактировать событие, изменив/добавив дедлайн - должно обновиться
3. Попытаться установить дедлайн позже даты начала - показать ошибку валидации
4. Отобразится дедлайн на странице деталей события с красивым форматированием

## Замечания

- Дедлайн регистрации необязателен - события без него работают как раньше
- Поле работает как на странице создания, так и на странице редактирования
- Используется одна и та же Zod схема для обеих форм
- Все иконки и форматирование соответствуют существующему UI стилю
