# Реализация тегов для событий

## Описание

Добавлена возможность выбора и создания тегов для событий с ограничением максимум 3 тега на событие. Каждый организатор может создавать собственные теги.

## Основные изменения

### 1. API типы и сервисы

#### `src/api/services/event.types.ts`
- Добавлено поле `tagIds?: string[]` в `CreateEventRequest`
- Обновлено поле `tags` в типе `Event` с `string[]` на структурированный массив объектов `{ id, name, slug }`

#### `src/api/services/tagsService.ts`
- Добавлен интерфейс `CreateTagParams` для создания тега
- Добавлен метод `create()` в `organizationTagsService` для создания тегов организации
- Добавлен метод `create()` в `eventTagsService` для создания тегов событий

### 2. Валидация

#### `src/features/events/lib/schemas/create-event-schema.ts`
- Добавлено поле `tagIds` в схему с валидацией:
  - Тип: массив строк
  - Максимум: 3 элемента
  - Опционально

### 3. API хуки

#### `src/features/events/api/use-event-tags.ts` (новый файл)
Создан модуль с хуками для работы с тегами событий:

**Теги событий:**
- `useEventTags(params?)` - получение всех доступных тегов
- `useEventTagsById(eventId)` - получение тегов конкретного мероприятия
- `useAssignEventTags()` - назначение тегов мероприятию

**Теги организации:**
- `useOrganizationTags(params?)` - получение тегов организации
- `useCreateOrganizationTag()` - создание нового тега организации
- `useDeleteOrganizationTag()` - удаление кастомного тега организации

### 4. UI компоненты

#### `src/shared/ui/tags-multi-select-creatable.tsx` (новый компонент)
Расширенная версия компонента выбора тегов с возможностью создания новых:

**Возможности:**
- Выбор существующих тегов из списка
- Создание новых тегов прямо в интерфейсе
- **Кнопка управления тегами** (иконка шестеренки)
- Ограничение максимального количества тегов (по умолчанию 3)
- Поиск по тегам
- Визуальная индикация выбранных тегов
- Индикация достижения лимита
- Защита от дублирования тегов

#### `src/shared/ui/tags-manager-dialog.tsx` (новый компонент)
Диалог для управления кастомными тегами организации:

**Возможности:**
- Просмотр всех тегов организации
- Поиск по тегам
- Удаление своих кастомных тегов
- Подтверждение удаления с предупреждением
- Отображение даты создания тега
- Визуальная индикация процесса удаления

**Пропсы:**
```typescript

  placeholder?: string;
  emptyText?: string;
  searchPlaceholder?: string;
  createText?: string;
  disabled?: boolean;
  className?: string;
  isCreating?: boolean;                  // Индикатор создания тега
}
```

## API эндпоинты

### event-tags (Теги событий)

#### Получить все доступные теги
```
GET /api/v1/events/tags
Query параметры:
  - search?: string
  - limit?: number

Response:
{
  data: Array<{ id: string, name: string, slug: string }>,
  total: number
}
```

#### Получить теги мероприятия
```
GET /api/v1/events/{id}/tags

Response:
{
  data: Array<{ id: string, name: string, slug: string }>,
  total: number
}
```

#### Назначить теги мероприятию
```
PUT /api/v1/events/{id}/tags
Body:
{
  tagIds: string[]
}
```

### organization-tags (Теги организации)

#### Создать кастомный тег организации
```
POST /api/v1/organizations/tags
Body:
{
  name: string
}

Response:
{
  id: string,
  name: string,
  slug: string,
  createdAt: string
}
```

#### Получить теги организации
```
GET /api/v1/organizations/tags
Query параметры:
  - search?: string
  - limit?: number

Response:
{
  data: Array<{ id: string, name: string, slug: string }>,
  total: number
}
```

#### Удалить кастомный тег
```
DELETE /api/v1/organizations/tags/{id}
```

## Использование

### Создание события с тегами

1. Открыть форму создания события
2. В разделе "Дополнительные настройки" найти поле "Теги"
3. Выбрать существующие теги из списка или создать новые:
   - Для выбора: кликнуть на тег в выпадающем списке
   - Для создания: ввести название нового тега и кликнуть "Создать тег"
4. Максимум 3 тега
5. При достижении лимита появится предупреждение

### Управление тегами организации

1. В форме создания/редактирования события найти поле "Теги"
2. Кликнуть на иконку **шестеренки** (⚙️) рядом с полем поиска
3. Откроется диалог "Управление тегами":
   - Просмотр всех своих тегов
   - Поиск по названию
   - Удаление тега кнопкой корзины
4. При удалении тега появится подтверждение
5. Удаленный тег автоматически удалится из всех событий

### Редактирование тегов события

1. Открыть страницу события
2. Перейти в режим редактирования
3. В разделе "Дополнительные настройки" изменить теги
4. Сохранить изменения

## Валидация

- **Максимум тегов**: 3
- **Уникальность**: Нельзя создать тег с названием, которое уже существует
- **Поле опциональное**: Можно создать событие без тегов

## Типизация

Все компоненты и хуки полностью типизированы с использованием TypeScript для обеспечения типобезопасности.

## Архитектура

Реализация следует принципам FSD (Feature-Sliced Design):
- **API слой** (`api/services`) - сервисы и типы
- **Features слой** (`features/events`) - хуки и бизнес-логика
- **Shared слой** (`shared/ui`) - переиспользуемые UI компоненты
- **Валидация** - централизована в схемах Zod

## Совместимость

- Компонент `TagsMultiSelectCreatable` совместим с существующим `TagsMultiSelect`
- API совместим с существующей структурой событий
- Теги опциональны, не ломают существующий функционал
