# Изменения полей соцсетей — для фронтенда

## Пользовательский UI

**Где:** форма редактирования профиля пользователя (обновление профиля).

**Поля соцсетей (все необязательные):**

| Поле          | Описание        |
|---------------|-----------------|
| `linkedinUrl` | LinkedIn        |
| `instagramUrl`| Instagram       |
| `facebookUrl` | Facebook        |
| `xUrl`        | X (Twitter)     |
| `websiteUrl`  | Личный сайт     |

**Что изменилось:** убраны `twitterUrl` и отдельное поле X; добавлены `instagramUrl`, `facebookUrl`; оставлено одно поле X — `xUrl`. В ответах API и при PATCH/PUT используйте эти имена полей.

---

## Супер-админский UI

**Где:** форма редактирования пользователя (админка: редактирование юзера по ID).

**Поля соцсетей (все необязательные):** те же, что и выше — `linkedinUrl`, `instagramUrl`, `facebookUrl`, `xUrl`, `websiteUrl`.

**Что изменилось:** аналогично пользовательскому UI — убраны `twitterUrl` и дублирующее поле X; добавлены `instagramUrl`, `facebookUrl`; для X используется только `xUrl`.
