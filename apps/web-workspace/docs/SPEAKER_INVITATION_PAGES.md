# Публичные страницы приглашений спикеров

## Обзор

Реализованы публичные страницы для обработки email-приглашений спикеров. Когда спикер получает приглашение на email, он может перейти по ссылке и принять или отклонить приглашение.

## Страницы

### 1. Страница принятия приглашения

**URL:** `/speaker-invitation/accept?token={invitationToken}`

**Файл:** `src/pages/speaker-invitation/accept/ui/accept-invitation-page.tsx`

**Функциональность:**
- Загружает информацию о приглашении по токену
- Отображает детали мероприятия (название, дата, организатор)
- Показывает важную информацию:
  - Срок действия приглашения (48 часов)
  - Необходимость регистрации в системе
  - Возможность обновить профиль после принятия
- Позволяет принять приглашение одним кликом
- Обрабатывает различные статусы:
  - `pending` - ожидает ответа (можно принять)
  - `accepted` - уже принято
  - `rejected` - уже отклонено
  - `expired` - истёк срок
- Показывает успешное подтверждение после принятия

**API эндпоинты:**
- `GET /api/v1/speakers/invitation/{token}` - получить информацию о приглашении
- `POST /api/v1/speakers/invitation/accept` - принять приглашение

### 2. Страница отклонения приглашения

**URL:** `/speaker-invitation/reject?token={invitationToken}`

**Файл:** `src/pages/speaker-invitation/reject/ui/reject-invitation-page.tsx`

**Функциональность:**
- Загружает информацию о приглашении по токену
- Отображает детали мероприятия
- Позволяет указать причину отказа (опционально, до 500 символов)
- Позволяет отклонить приглашение
- Предоставляет возможность вернуться к принятию
- Обрабатывает статусы приглашения
- Показывает подтверждение после отклонения

**API эндпоинты:**
- `GET /api/v1/speakers/invitation/{token}` - получить информацию о приглашении
- `POST /api/v1/speakers/invitation/reject` - отклонить приглашение

## Дизайн и UX

### Цветовые схемы

**Страница принятия:**
- Градиент: blue → indigo → purple (приглашение)
- Градиент: emerald → teal (успешное принятие)
- Акцент: зелёный для кнопки "Принять"

**Страница отклонения:**
- Градиент: red → rose (отклонение)
- Градиент: slate (подтверждение отклонения)
- Акцент: красный для кнопки "Отклонить"

### Компоненты UI

- **Card** - основной контейнер с тенью
- **Gradient Headers** - красочные заголовки с градиентами
- **Status Badges** - цветные бейджи для статусов
- **Loading States** - анимированные индикаторы загрузки
- **Error Messages** - информативные сообщения об ошибках
- **Success Screens** - экраны подтверждения с иконками

### Адаптивность

- Мобильные устройства: `max-w-md`
- Планшеты/Десктоп: `max-w-2xl`
- Гибкие кнопки: `flex-col sm:flex-row`
- Отступы: `p-4` на мобильных

## Состояния приглашения

| Статус | Описание | Действия |
|--------|----------|----------|
| `pending` | Ожидает ответа | Можно принять или отклонить |
| `accepted` | Приглашение принято | Показать сообщение "Уже принято" |
| `rejected` | Приглашение отклонено | Показать сообщение "Уже отклонено" |
| `expired` | Истёк срок действия | Показать сообщение об истечении |

## Обработка ошибок

### Отсутствие токена

```
URL: /speaker-invitation/accept
Ошибка: "Токен приглашения не указан"
```

### Неверный токен
```
API Response: 404
Ошибка: "Не удалось загрузить приглашение"
```

### Ошибка сети
```
Ошибка: Текст ошибки из API response
```

## Роутинг

Добавлены публичные роуты в `src/app/providers/router/router.tsx`:

```typescript
// Speaker Invitation Routes (Public - no auth required)
{
  path: '/speaker-invitation/accept',
  element: withSuspense(<AcceptInvitationPage />),
  errorElement: withSuspense(<ErrorPage />),
},
{
  path: '/speaker-invitation/reject',
  element: withSuspense(<RejectInvitationPage />),
  errorElement: withSuspense(<ErrorPage />),
}
```

**Важно:** Эти страницы доступны БЕЗ авторизации, т.к. спикер может быть не зарегистрирован в системе.

## Интеграция с API

### Типы данных

```typescript
type SpeakerInvitation = {
  id: string
  token: string
  eventId: string
  eventTitle: string
  eventStartDate: string
  eventEndDate: string
  organizerName: string
  speakerEmail: string
  speakerName: string
  speakerPosition?: string
  status: 'pending' | 'accepted' | 'rejected' | 'expired'
  expiresAt: string
  createdAt: string
}

type AcceptInvitationRequest = {
  token: string
  bio?: string
  company?: string
  linkedinUrl?: string
  twitterUrl?: string
  websiteUrl?: string
}

type RejectInvitationRequest = {
  token: string
  reason?: string
}
```

### Методы API

Используются существующие методы из `speakersService`:

```typescript
// Получить информацию о приглашении
speakersService.getInvitation(token: string): Promise<SpeakerInvitation>

// Принять приглашение
speakersService.acceptInvitation(data: AcceptInvitationRequest): Promise<Speaker>

// Отклонить приглашение
speakersService.rejectInvitation(data: RejectInvitationRequest): Promise<{ success: boolean }>
```

## Примеры использования

### Email от организатора

Спикер получает email с текстом:

> Организация **Test ООО** приглашает вас выступить в качестве спикера на мероприятии **Check Activity**.
>
> [✓ Принять приглашение] [✗ Отклонить]

При клике на кнопку переходит на соответствующую страницу.

### Переход по ссылке

```
https://eventflow.uz/speaker-invitation/accept?token=ed7769ccec1e...
```

1. Загружается информация о приглашении
2. Отображается красивая страница с деталями
3. Спикер может принять или отклонить
4. После действия показывается подтверждение

## Заметки

- Страницы полностью публичные (без авторизации)
- Токен является единственным способом идентификации
- Токены истекают через 48 часов с момента создания
- После принятия спикер может обновить свой профиль в системе
- Организатор получает уведомление о решении спикера
