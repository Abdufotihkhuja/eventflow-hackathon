# Быстрое руководство: Программа мероприятия

## 🎯 Что было исправлено

### Проблема
При создании программы мероприятия получали ошибку 400 от API с сообщениями о неправильной структуре данных.

### Решение
✅ Приведена структура данных в соответствие с реальным backend API  
✅ Добавлена полная обработка ошибок с toast уведомлениями  
✅ Улучшен UI/UX до высоких стандартов  

## 📋 Правильная структура данных

Backend ожидает следующую структуру:

```json
{
  "title": "Открытие конференции",
  "type": "KEYNOTE",
  "startTime": "10:00",
  "duration": 60,
  "sortOrder": 1
}
```

**Важно:**
- ❌ НЕ отправляйте поле `date`
- ❌ НЕ отправляйте поле `endTime`
- ✅ Используйте `duration` в минутах
- ✅ `type` - обязательное поле (enum)

## 🎨 Типы активностей

| Тип | Описание | Иконка |
|-----|----------|--------|
| `KEYNOTE` | Основной доклад | 🎤 |

## 🚀 Как использовать

### 1. Открыть программу мероприятия
Перейдите в детали события → вкладка "Программа"

### 2. Добавить пункт программы
1. Нажмите **"Добавить пункт"**
2. Заполните поля:
   - **Название** (обязательно)
   - **Тип активности** (обязательно)
   - **Время начала** (обязательно)
   - **Длительность в минутах** (обязательно, минимум 1)
   - **Порядок сортировки** (опционально)
3. Нажмите **"Сохранить"**

### 3. Редактировать пункт
1. Кликните на карточку пункта программы
2. Нажмите **"Редактировать"**
3. Измените нужные поля
4. Нажмите **"Сохранить"**

### 4. Удалить пункт
1. Раскройте карточку пункта
2. Нажмите кнопку с иконкой корзины
3. Подтвердите удаление

## ⚠️ Валидация

### На стороне клиента
- Название не может быть пустым
- Длительность >= 1 минута

### На стороне сервера
- `type` должен быть одним из допустимых значений
- `duration` должен быть целым числом >= 1
- Поля `date` и `endTime` не должны присутствовать

## 🐛 Частые ошибки

### "property date should not exist"
❌ Не отправляйте поле `date` в запросе

### "duration must not be less than 1"
❌ Укажите длительность >= 1 минута

### "type must be one of the following values..."
❌ Используйте только допустимые значения для типа
