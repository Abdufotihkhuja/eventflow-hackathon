# Улучшение UI выбора спикеров в агенде

## Проблема

При создании/редактировании элемента программы (агенды) не было понятно, как прикрепить спикеров. UI выбора спикеров был скрыт, если в событии еще не было добавлено ни одного спикера.

## Решение

Изменен компонент `AgendaManager` для улучшения UX выбора спикеров:

### 1. **Всегда показываем секцию "Спикеры"**

Теперь секция отображается всегда, независимо от наличия спикеров:

```tsx
{/* Было */}
{speakers.length > 0 && (
  <div>Спикеры...</div>
)}

{/* Стало */}
<div>
  <Label>Спикеры</Label>
  {speakers.length > 0 ? (
    // UI выбора
  ) : (
    // Пустое состояние с подсказкой
  )}
</div>
```

### 2. **Пустое состояние с инструкцией**

Если спикеры не добавлены к событию, показываем понятное сообщение:

```
┌─────────────────────────────────────┐
│              👤                     │
│    Спикеры не добавлены            │
│                                     │
│  Перейдите на вкладку "Спикеры"    │
│  чтобы добавить спикеров к событию │
└─────────────────────────────────────┘
```

### 3. **Улучшенный заголовок с информацией**

Добавлен счетчик доступных спикеров:

```
Спикеры                    Доступно: 5
┌─────────────────────────────────────┐
│ ☐ Иван Петров                      │
│ ☑ Мария Сидорова                   │
│ ☐ Алексей Иванов                   │
└─────────────────────────────────────┘
Выбрано: 1 из 5
```

### 4. **Динамическая подсказка**

Показываем разные подсказки в зависимости от состояния:

- **Ни один не выбран**: "Отметьте спикеров, которые участвуют в этом пункте программы"
- **Выбраны спикеры**: "Выбрано: N из M"

## UI до и после

### До:
- Секция "Спикеры" скрыта, если спикеров нет
- Непонятно, как добавить спикеров
- Нет информации о количестве доступных спикеров

### После:
- Секция всегда видна
- Понятные инструкции в пустом состоянии
- Счетчик доступных и выбранных спикеров
- Подсказка о том, что нужно сделать

## Режим просмотра

В режиме просмотра элемента программы спикеры отображаются с бейджами:

```
Спикеры:
┌──────────────┐ ┌──────────────┐
│ 👤 И. Петров │ │ 👤 М. Сидор. │
└──────────────┘ └──────────────┘
```

## Измененные файлы

## Как использовать

1. **Добавьте спикеров к событию:**
   - Перейдите на вкладку "Спикеры"
   - Нажмите "Пригласить спикера"
   - Заполните данные спикера

2. **Прикрепите спикеров к элементу программы:**
   - Перейдите на вкладку "Программа"
   - Создайте или отредактируйте элемент программы
   - В секции "Спикеры" отметьте нужных спикеров галочками
   - Нажмите "Сохранить"
