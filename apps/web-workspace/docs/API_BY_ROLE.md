# API по ролям — индекс документации

Префикс всех путей: **`/api/v1`**.

В каждом документе по роли указаны **пути (paths)** и **DTO**: поля запросов (Body, Query) и ответов, где применимо.

## Краткая сводка по доступу

- **Супер-админ** — полный доступ к админке: пользователи, организации (верификация), события (модерация, топовые), блог (модерация), категории и подборки (CRUD), статистика.
- **Организатор / MEMBER** — своя организация, участники, события организации (по правам EVENTS\_\*), регистрации, посещаемость, сертификаты, билеты, подписчики, заявки на связь, блог организации, доски.
- **Пользователь (USER)** — свой профиль, календарь, сертификаты, сохранённые статьи, подписки на организаторов, заявки на связь, регистрации на события, сохранённые мероприятия, комментарии к событиям и блогу, лайки, билеты.
- **Публичные** — без JWT: статистика, каталог событий, описания, теги, категории, подборки, комментарии (чтение), блог (чтение), auth и verification endpoints.

Для деталей по каждому endpoint и полям DTO используйте соответствующий документ выше.
