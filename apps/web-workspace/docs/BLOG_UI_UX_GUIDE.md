# Руководство по UI/UX модуля блога

Комплексное руководство по дизайну и пользовательскому опыту модуля блога в EventFlow.

## Обзор улучшений

Модуль блога разработан с фокусом на высокие стандарты UI/UX и современные практики дизайна. Каждый элемент продуман для обеспечения максимального удобства пользователей.

## Навигация

### Главное меню

Добавлены три новых раздела в навигацию приложения:

#### Для организаторов:
- **"Мой блог"** (`/my-blog`) — управление статьями
  - Иконка: FileText
  - Видимость: только организации
  - Расположение: секция "Управление"

#### Для всех пользователей:
- **"Блог"** (`/blog`) — публичный блог
  - Иконка: BookOpen
  - Видимость: все пользователи
  - Расположение: новая секция "Контент"

- **"Сохранённые"** (`/saved-blog`) — закладки
  - Иконка: Bookmark
  - Видимость: авторизованные пользователи
  - Расположение: секция "Контент"

### Breadcrumbs

Для каждой страницы настроены хлебные крошки:
```
Главная → Блог
Главная → Мой блог
Главная → Сохранённые
```

## Публичные страницы

### BlogListPage (`/blog`)

**Hero секция:**
- Градиентный фон с акцентом на primary цвет
- Badge "Новое в блоге" с иконкой Sparkles
- Крупный заголовок (text-4xl/5xl)
- Описательный подзаголовок
- Декоративные элементы справа

**Фильтры:**
- Поиск с иконкой
- Сортировка с иконками для каждой опции:
  - "Сначала новые" — Sparkles
  - "Популярные" — TrendingUp

**Сетка статей:**
- Адаптивная сетка: 1 колонка (mobile) → 2 (tablet) → 3 (desktop)
- Gap между карточками: 1.5rem (6)

### BlogPostPage (`/blog/:slug`)

**Hero секция:**
- Градиентный фон от muted/50 к background
- Увеличенные отступы: py-16/20
- Теги статьи в начале
- Крупный заголовок (text-4xl/5xl)
- Мета-информация: автор, дата, просмотры
- Кнопки действий: лайк, сохранить, поделиться

**Контент:**
- Максимальная ширина: 4xl (896px)
- Обложка с shadow-lg
- Цитата-описание с border-left
- Rich Text контент в prose-режиме
- Теги внизу статьи

**Комментарии:**
- Отдельная секция с border-top
- Форма добавления комментария
- Список комментариев с аватарами

### SavedBlogPage (`/saved-blog`)

**Header:**
- Золотистая карточка с иконкой закладки
- Счётчик сохранённых статей
- Описательный текст

**Empty State:**
- Иконка закладки в круге (amber цвет)
- Дружелюбное сообщение
- CTA кнопка "Перейти к блогу"

## Страницы управления

### MyBlogPage (`/my-blog`)

**Header:**
- Заголовок с tracking-tight
- Описание функционала
- Крупная CTA кнопка с shadow

**Статистика (если есть статьи):**
```
┌─────────────┬─────────────┬─────────────┬─────────────┐
│ Всего статей│ На модерации│ Опубликовано│  Черновиков │
│     24      │      3      │      18     │      3      │
└─────────────┴─────────────┴─────────────┴─────────────┘
```

- 4 карточки с метриками
- Цветовая индикация статусов:
  - Amber (pending)
  - Emerald (published)
  - Slate (draft)

**Фильтры:**
- В отдельном контейнере с bg-muted/30
- Поиск, статус, сортировка, порядок

**Empty State:**
- Анимированная иконка с pulse
- Список преимуществ:
  - Rich Text редактор
  - Аналитика и статистика
  - Модерация и публикация
- Крупная CTA кнопка

### BlogEditorPage (`/my-blog/new`, `/my-blog/:id/edit`)

**Layout:**
- Страница с bg-muted/10
- Контент в белой карточке (rounded-xl, border, shadow)
- Максимальная ширина: 4xl

**Header:**
- Кнопка "Назад"
- Заголовок (text-3xl)
- Badge статуса
- Время последнего изменения

**Форма:**
- Поля: заголовок, обложка, описание, контент, настройки
- Preview обложки при вводе URL
- Rich Text редактор: min-height 400px
- Switch для комментариев с описанием

**Actions:**
- Две кнопки: "Сохранить" и "Сохранить и отправить на модерацию"
- Иконки для кнопок

**Rejection Reason:**
- Красная карточка с border-destructive
- Показывается только при статусе REJECTED

### MyBlogPostPage (`/my-blog/:id`)

**Header:**
- Badge статуса
- Заголовок статьи
- Информация об авторе и датах
- Статистика: просмотры, лайки, комментарии

**Actions Menu:**
- Dropdown с действиями:
  - Редактировать (DRAFT, REJECTED)
  - Отправить на модерацию (DRAFT)
  - Опубликовать (APPROVED)
  - Снять с публикации (PUBLISHED)
  - Посмотреть на сайте (PUBLISHED)
  - Удалить

**Контент:**
- Обложка в полную ширину
- Краткое описание (italic)
- Prose контент
- Теги

## Анимации и переходы

### Hover эффекты:
```css
/* Карточка статьи */
transition-all duration-300
hover:-translate-y-1
hover:border-primary/50
hover:shadow-xl

/* Обложка */
transition-all duration-500
hover:scale-110
hover:brightness-110

/* Ссылки в навигации */
transition-colors
hover:bg-accent
```

### Loading состояния:
- Skeleton для карточек
- Spinner для кнопок
- Pulse анимация для иконок

## Адаптивность

### Breakpoints:
```
sm: 640px  — mobile landscape
md: 768px  — tablet
lg: 1024px — desktop
xl: 1280px — large desktop
```

### Grid системы:
```css
/* Карточки статей */
mobile:  grid-cols-1
tablet:  md:grid-cols-2
desktop: lg:grid-cols-3

/* Статистика */
mobile:  grid-cols-2
desktop: md:grid-cols-4
```

### Typography:
```css
/* Заголовки */
mobile:  text-3xl/4xl
desktop: md:text-4xl/5xl

/* Padding */
mobile:  px-4 py-8
desktop: md:px-4 md:py-12
```

## Цветовая палитра

### Semantic colors:
```
primary     — основной акцент (синий)
destructive — ошибки/удаление (красный)
muted       — фон второстепенных элементов
accent      — hover состояния
border      — границы элементов
```

### Status colors:
```
slate   — черновики
amber   — на модерации
emerald — одобрено/опубликовано
rose    — отклонено
```

Все компоненты полностью поддерживают тёмную тему:
- Использование CSS переменных

- Корректная работа градиентов

## Accessibility (A11y)

### Semantic HTML:
- `<article>` для статей
- `<nav>` для навигации
- `<main>` для основного контента
- `<section>` для разделов

### ARIA атрибуты:
- aria-label для иконок-кнопок
- role для интерактивных элементов
- aria-expanded для dropdown

### Keyboard navigation:
- Tab index для всех интерактивных элементов
- Focus indicators (ring-2, ring-offset-2)
- Escape для закрытия модалов

### Screen readers:
- Alt текст для изображений
- Описательные labels для форм
- Семантические заголовки (h1-h6)

## Производительность

### Image optimization:
- Lazy loading для обложек
- Aspect ratio для избежания CLS
- object-cover для корректного масштабирования

### Code splitting:
- Lazy import страниц через React.lazy
- Suspense с fallback компонентами

### Animations:
- CSS transitions (GPU accelerated)
- transform вместо position changes
- will-change для анимируемых элементов

## Best Practices

### 1. Консистентность
- Единые отступы (spacing scale)
- Общая цветовая палитра
- Стандартные размеры компонентов

### 2. Feedback
- Loading состояния для всех асинхронных действий
- Success/error toast уведомления
- Disabled состояния при отправке форм

### 3. Progressive enhancement
- Базовый функционал работает без JS
- Graceful degradation для старых браузеров
- Fallback для неподдерживаемых фич

### 4. Mobile-first
- Дизайн начинается с mobile
- Progressive enhancement для больших экранов
- Touch-friendly элементы (min 44x44px)
