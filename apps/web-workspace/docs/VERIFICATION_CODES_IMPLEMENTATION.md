# Реализация страницы "Коды верификации"

## Описание

Страница для супер-администратора, отображающая все коды верификации, отправленные пользователям и организациям системы.

## Функциональность

### Основные возможности

1. **Просмотр кодов** — отображение всех кодов верификации в табличном виде
2. **Поиск** — поиск по email получателя
3. **Фильтрация** — фильтрация по типу кода и статусу использования
4. **Копирование кода** — быстрое копирование кода в буфер обмена
5. **Пагинация** — постраничная навигация (15 записей на страницу)

### Типы кодов

- **Email верификация** — коды для подтверждения email пользователей/организаций
- **Сброс пароля** — коды для восстановления доступа
- **Смена email** — коды для подтверждения смены email адреса

### Отображаемая информация

Для каждого кода показывается:

- **Email** — адрес получателя (с новым email для смены)
- **Тип получателя** — пользователь или организация
- **Код** — сам код верификации (с кнопкой копирования)
- **Тип** — тип кода с иконкой (Email верификация/Сброс пароля/Смена email)
- **Статус** — использован, активен или истёк (с цветовым индикатором)
- **Дата создания** — когда код был создан
- **Дата истечения** — когда код истекает (красным, если уже истёк)
- **Попытки** — количество попыток использования
- **Дата использования** — когда код был использован (если применимо)

## Технические детали

### API Endpoint

```
GET /api/v1/super-admin/verification-codes
```

**Параметры запроса:**
- `page` — номер страницы
- `limit` — количество записей на страницу
- `search` — поиск по email
- `type` — фильтр по типу кода (`EMAIL_VERIFICATION` | `PASSWORD_RESET` | `EMAIL_CHANGE`)
- `isUsed` — фильтр по статусу использования

**Структура ответа:**
```json
{
  "data": [
    {
      "id": "string",
      "code": "string",
      "email": "string",
      "type": "EMAIL_VERIFICATION" | "PASSWORD_RESET" | "EMAIL_CHANGE",
      "actorType": "USER" | "ORGANIZATION",
      "actorId": "string",
      "newEmail": "string | null",
      "isUsed": "boolean",
      "usedAt": "string | null",
      "expiresAt": "string",
      "attempts": "number",
      "createdAt": "string"
    }
  ],
  "total": "number",
  "page": "number",
  "limit": "number",
  "totalPages": "number"
}
```

### Используемые компоненты

- `DataTable` — таблица с сортировкой и пагинацией
- `Card` — карточка для фильтров
- `Input` — поле поиска

- `Badge` — бейджи для типов и статусов
- `Button` — кнопки действий

### Цветовая схема

**Типы кодов:**
- Email верификация — синий (`bg-blue-100 text-blue-700`)
- Сброс пароля — янтарный (`bg-amber-100 text-amber-700`)
- Смена email — фиолетовый (`bg-purple-100 text-purple-700`)

**Статусы:**
- Использован — зелёный (`bg-emerald-100 text-emerald-700`)
- Истёк — красный (`bg-red-100 text-red-700`)
- Активен — серый (`bg-slate-100 text-slate-700`)

**Тёмная тема:**
Все цвета имеют варианты для тёмной темы (`dark:bg-*-950 dark:text-*-300`)

## Маршрутизация

**URL:** `/admin/verification-codes`

**Навигация:** Admin → Управление → Коды

## Особенности реализации

1. **Автоматическое обновление** — данные кешируются на 30 секунд (`staleTime: 30 * 1000`)
2. **Копирование кода** — реализовано через Clipboard API с toast-уведомлением
3. **Умная индикация статуса** — автоматическое определение истёкших кодов с визуальным выделением
4. **Отображение новых email** — для типа "Смена email" показывается целевой адрес
5. **Тип получателя** — отображается USER или ORGANIZATION под email
6. **Попытки использования** — отдельная колонка с количеством попыток
7. **Responsive дизайн** — адаптивная вёрстка для мобильных устройств
8. **Поддержка тёмной темы** — все цвета адаптированы для dark mode

## Дизайн

Страница следует общей концепции проекта:

- Использует те же компоненты и стили, что и другие страницы super-admin
- Единая цветовая схема с поддержкой тёмной темы
- Консистентная типографика и отступы
- Знакомые паттерны взаимодействия (поиск, фильтры, таблица)

## Примеры использования

### Поиск кода по email

1. Введите email в поле поиска
2. Таблица автоматически обновится с результатами

### Фильтрация по типу

1. Выберите тип кода в выпадающем списке
2. Таблица покажет только коды выбранного типа

### Копирование кода

1. Нажмите на кнопку с кодом
2. Код скопируется в буфер обмена
3. Появится уведомление об успешном копировании
