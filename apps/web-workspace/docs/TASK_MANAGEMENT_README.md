# Модуль управления задачами (Task Management)

## Обзор

Полнофункциональный модуль управления задачами, объединяющий лучшие практики от Trello и Jira. Модуль интегрирован с существующей системой пользователей и следует архитектуре FSD.

## Основные возможности

### От Trello
- ✅ **Канбан-доска** с колонками для визуализации процесса
- ✅ **Карточки задач** с кратким обзором информации
- ✅ **Метки (Labels)** с настраиваемыми цветами
- ✅ **Чек-листы** внутри задач для отслеживания подзадач
- ⏳ **Вложения** (структура готова, требуется реализация upload)

### От Jira
- ✅ **Типы задач**: Task, Bug, Story, Epic
- ✅ **Приоритеты**: от Минимального до Критического
- ✅ **Статусы** с гибким workflow: Backlog → Todo → In Progress → In Review → Done
- ✅ **Оценка времени** (time tracking): estimated, spent, remaining
- ✅ **Связи между задачами**: blocks, is_blocked_by, relates_to, duplicates
- ✅ **Назначение исполнителей**
- ✅ **Спринты** (структура готова)

### Дополнительные возможности
- 🔍 **Фильтрация и поиск** по статусу, приоритету, типу, исполнителю
- 📊 **Статистика досок**: количество задач, прогресс
- 💬 **Комментарии** (структура готова)
- 📝 **История активности** (структура готова)
- 🎨 **Dark mode** поддержка

## Архитектура

Модуль следует FSD (Feature-Sliced Design) архитектуре:

### Entities
```
src/entities/
├── task/           # Основные типы и константы задач
│   ├── lib/
│   │   ├── constants.ts  # Типы, статусы, приоритеты
│   │   └── types.ts      # Task, Label, Comment, etc.
│   └── index.ts
└── board/          # Дополнительные типы досок
    ├── lib/
    │   └── types.ts
    └── index.ts
```

### API Layer
```
src/api/services/
├── task.types.ts       # API типы (DTOs)
├── tasksService.ts     # CRUD операции для задач
├── board.types.ts      # Типы досок
└── boardsService.ts    # CRUD операции для досок
```

### Features

│   └── ui/            # UI компоненты
│       ├── task-form/

│   └── api/
│       ├── use-boards-query.ts
│       ├── use-board-query.ts

## Роутинг

Добавлены следующие маршруты:

- `/tasks/boards` - Список всех досок
- `/tasks/boards/:boardId` - Канбан-доска с задачами
- `/tasks/:taskId` - Детальная информация о задаче

## Интеграция с системой пользователей

Модуль интегрирован с актуальной системой участников/сотрудников:

- **Назначение исполнителей** - используются реальные пользователи системы
- **Создатели задач** - автоматически привязываются к текущему пользователю
- **Участники досок** - управление доступом к доскам
- **История активности** - отслеживание действий пользователей

## Используемые технологии

- **React Router DOM 7** - навигация
- **TanStack Query** - работа с API и кэширование
- **React Hook Form + Zod** - управление формами и валидация
- **Tailwind + Radix + локальные shared/ui компоненты** - UI компоненты
- **TailwindCSS** - стилизация
- **TypeScript** - типобезопасность

## Что готово к использованию

✅ **Полностью реализовано:**
- Создание, редактирование, удаление досок
- Создание, редактирование, удаление задач
- Канбан-доска с колонками
- Карточки задач со всей необходимой информацией
- Фильтрация и поиск задач
- Детальная страница задачи
- Типизация всех данных
- React Query хуки для всех операций

✅ **Структура готова, требуется backend:**
- Чек-листы
- Комментарии
- Вложения (файлы)
- Спринты
- История активности
- Связи между задачами

## Что можно добавить в будущем

### Высокий приоритет
1. **Drag & Drop** - перетаскивание задач между колонками
   - Рекомендуется: `@dnd-kit/core` или `react-beautiful-dnd`
   - Хук `useMoveTask` уже готов к интеграции

2. **Комментарии** - полная реализация системы комментариев
   - API уже подготовлено (`taskService.getTaskComments`, `createComment`, etc.)

3. **Вложения** - загрузка и управление файлами
   - API готово (`taskService.uploadAttachment`, `deleteAttachment`)

### Средний приоритет
4. **Спринты** - полная реализация Agile-спринтов
   - доменная модель частично подготовлена, но отдельного `sprintService` сейчас нет

5. **История активности** - отображение всех изменений задачи
   - `taskService.getTaskActivities` готово

6. **Связи между задачами** - визуализация зависимостей
   - `taskService.createTaskLink`, `deleteTaskLink` готовы

### Низкий приоритет
7. **Бэклог** - отдельная страница для неразобранных задач
8. **Календарь** - view задач в виде календаря
9. **Timeline** - view задач в виде временной шкалы (Gantt)
10. **Уведомления** - оповещения о важных событиях
11. **Экспорт** - выгрузка задач в различных форматах

## API требования

Для полной работы модуля backend должен предоставлять следующие эндпоинты:

### Boards
- `GET /boards` - список досок
- `GET /boards/:id` - детали доски
- `POST /boards` - создание доски
- `PATCH /boards/:id` - обновление доски
- `DELETE /boards/:id` - удаление доски

### Tasks
- `GET /tasks` - список задач (с фильтрами)
- `GET /tasks/:id` - детали задачи
- `POST /tasks` - создание задачи
- `PATCH /tasks/:id` - обновление задачи
- `PATCH /tasks/:id/move` - перемещение задачи
- `DELETE /tasks/:id` - удаление задачи

### Дополнительно
- Comments, Attachments, Checklists, Sprints, Labels endpoints
- См. полный список в `src/api/services/tasksService.ts`
