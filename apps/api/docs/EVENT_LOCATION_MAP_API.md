# Локация мероприятия и карта (Yandex Maps)

## Обзор

При создании и редактировании мероприятия можно указать координаты места проведения. Они возвращаются в API события и используются на фронте для отображения карты (например, Yandex Maps) на странице мероприятия.

## Поля API

| Поле        | Тип    | Обязательное | Описание                                                                                  |
| ----------- | ------ | ------------ | ----------------------------------------------------------------------------------------- |
| `latitude`  | number | Нет          | Широта (-90…90). Для отображения метки на карте.                                          |
| `longitude` | number | Нет          | Долгота (-180…180).                                                                       |
| `placeId`   | string | Нет          | ID места в Yandex (например `ymapsbm1://org/...`). Опционально, для обратного геокодинга. |

- В **POST /events** и **PATCH /events/:id** эти поля опциональны.
- При **PATCH** передача `null` для любого из полей очищает значение.
- Существующие поля `venue`, `address`, `city` по-прежнему используются для текстового отображения; координаты — для карты.

## Ответ API

В ответах получения события (по id/slug) объект события содержит:

```json
{
  "id": "...",
  "title": "...",
  "venue": "Конференц-зал «Узбекистан»",
  "address": "г. Ташкент, ул. Навои, 1",
  "city": "Ташкент",
  "latitude": 41.311151,
  "longitude": 69.279737,
  "placeId": "ymapsbm1://org/12345",
  ...
}
```

Если координаты не заданы, поля `latitude`, `longitude`, `placeId` будут `null`.

## Рекомендации для фронта (Yandex Maps)

### 1. Выбор места при создании/редактировании события

- **Yandex Maps JavaScript API 3.0**: [https://yandex.ru/dev/maps/jsapi/doc/3.0/](https://yandex.ru/dev/maps/jsapi/doc/3.0/)
- Подключите карту в форме создания/редактирования события (для формата offline/hybrid).
- Реализуйте:
  - **Поиск по адресу**: Yandex Geocoder — по введённому адресу получить координаты и поставить метку.
  - **Клик по карте**: при клике получать координаты (event.get('coords')), ставить метку, опционально — обратное геокодирование для подстановки `address`/`city`.
- После выбора места заполняйте в форме и отправляйте в API:
  - `latitude`, `longitude` — обязательно для карты;
  - при наличии — `placeId` из ответа геокодера/поиска;
  - при необходимости — `venue`, `address`, `city` из подсказок/геокодера.

### 2. Карта на странице мероприятия

- На странице события (по id или slug) запросить данные события (GET события).
- Если у события есть `latitude` и `longitude` (не `null`):
  - Инициализировать карту с центром `[latitude, longitude]`.
  - Добавить метку (Placemark) в этой точке.
  - Опционально: подпись/балун с текстом из `venue` или `address`.
- Если координат нет — блок с картой не показывать или показывать только текст места (`venue`, `address`, `city`).

### 3. Ключ API

- Получить ключ в [Кабинете разработчика Yandex](https://developer.tech.yandex.ru/) для JavaScript API и/или Геокодера.
- Хранить ключ в конфигурации фронта (переменные окружения), не передавать с бэкенда.

### 4. Пример проверки на фронте (отображать карту только при наличии координат)

```ts
const hasLocation = event.latitude != null && event.longitude != null;
if (hasLocation) {
  // Показать карту с центром [event.latitude, event.longitude] и меткой
}
```

Миграция БД добавляет колонки `latitude`, `longitude`, `place_id` в таблицу `events`. После применения миграции (`npx prisma migrate deploy` или `prisma migrate dev`) поля доступны в API.
